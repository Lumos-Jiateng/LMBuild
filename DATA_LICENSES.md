# Data sources and licences

The benchmark's own annotations are released with this repository. That covers the task definitions, the prompts, the
verified claims and their citations, the pools' composition, the in-the-wild images, the human ratings and the scores.
The geometry of the reference objects and of the pool parts comes from third-party datasets. Each keeps its own licence.
The licence string of every reference is in `benchmark/tasks/<task>/task.json` → `reference.license`, and a per-task
table is in `benchmark/README.md`.

| source | tasks | licence as recorded | note |
|---|---|---|---|
| Artiverse | 26 references, pool parts | gated on Hugging Face (`3dlg-hcvc/artiverse`); per-object licences inherited from the upstream asset sources | redistribution of the meshes needs the dataset's terms; users may need to accept them upstream |
| PartNeXt | 6 references, pool parts | CC BY 4.0; assets from Objaverse, ABO and 3D-FUTURE under their own terms | |
| Fusion 360 Gallery Assembly | 3 references, pool parts | CC BY-NC-SA 4.0 (Autodesk research licence) | non-commercial, share-alike |
| LDraw OMR via BrickNet | 5 references (+ alternates) | LDraw OMR models, CCAL 2.0 / CC BY 2.0 per the OMR terms | LDraw part meshes (`benchmark/assets/ldraw/`) follow the LDraw library licence |
| BrickComposer / BrickLink Studio | 5 references (`bc_*`) | per-model terms of the original Studio model; not established | |
| Curated open hardware | 5 references | not recorded in the task JSON: ASTRA quadruped and Hubert arm (MIT); Ploopy mouse and trackball (CERN-OHL), Ploopy headphones (CERN-OHL-S v2) | |
| Wikidata / Wikipedia | knowledge sources | CC0 (Wikidata), CC BY-SA 4.0 (Wikipedia text quoted in `knowledge/sources.json` and in claim citations) | pinned revisions |
| Images | in-the-wild condition images | generated by Qwen-Image-Edit-2511 from the reference renders | |
